# 🍷 Wine Quality Prediction

## 📌 Overview
This project predicts the quality of wine using Machine Learning based on its chemical properties such as acidity, sugar, alcohol, pH, sulphates, and more.

## 🚀 Features
- Predicts wine quality
- Data preprocessing
- Model training and evaluation
- Easy-to-understand code structure

## 🛠️ Technologies Used
- Python
- Jupyter Notebook / Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📂 Dataset
The project uses the Wine Quality dataset containing various physicochemical properties of wine and their quality ratings.

## ▶️ How to Run
1. Clone the repository.
2. Install the required libraries:
   ```
   pip install -r requirements.txt
   ```
3. Open the notebook and run all cells.

## 📊 Machine Learning Workflow
- Load Dataset
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Selection
- Model Training
- Model Evaluation
- Prediction

## 📈 Results
The trained model predicts wine quality with good accuracy on the test dataset.
